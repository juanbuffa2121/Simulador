Simulador de Exergía

Configurá las temperaturas de las fuentes, el calor entregado y el trabajo extraído. El cálculo de exergía se actualiza en tiempo real según el punto muerto que elijas.

💡 Cómo experimentar con el simulador
Probá modo Carnot: ΔXU ≈ 0. Pasá a Real y bajá W: aparece destrucción de exergía. Si subís W por encima del límite de Carnot → imposible (viola 2° principio). Poné TL > TH: cambia a máquina frigorífica automáticamente. Mové T0 para ver cómo cambia la exergía de las fuentes.
Exergía de cada componente del simulador
  • Fuentes de calor (caliente o fría): ΔX = (1 − T0/T) · Q, donde Q > 0 si recibe y Q < 0 si cede.
  • Trabajo: siempre 100% exergía. ΔX = +W si lo recibe, −W si lo entrega.
Regla conceptual · Exergía por intercambio de calor
  • T > T0 y recibe calor → gana exergía
  • T > T0 y cede calor → pierde exergía
  • T < T0 y recibe calor → pierde exergía
  • T < T0 y cede calor → gana exergía

A T = T0 el factor (1 − T0/T) = 0 → el calor no tiene valor exergético.

¿Qué es la exergía?

Propiedad que cuantifica la capacidad de producir trabajo de un sistema. Es el trabajo útil máximo obtenible si el sistema evoluciona hasta el equilibrio con un estado de referencia (T0, P0).

Es una medida del desequilibrio con el ambiente: a mayor desequilibrio, mayor exergía.

¿Por qué calor y trabajo no son iguales?

El 1° principio iguala todas las energías: ΔE = Q − W. Pero el 2° principio revela que tienen distinta calidad: 1000 kJ de trabajo levantan un peso directamente, mientras que 1000 kJ de calor solo pueden hacerlo parcialmente, y la fracción aprovechable depende de la temperatura de la fuente.

Variación de exergía · Fórmulas clave
Sistemas cerradosΔX = ΔU − T0 · ΔS + p0 · ΔV
Sistemas abiertos estacionariosΔX = ΔH − T0 · ΔS + ΔEc + ΔEp
Universo (sist. aislado: ΔU = 0, ΔV = 0)ΔXU = −T0 · ΔSU   →   como ΔSU ≥ 0, entonces ΔXU ≤ 0
Porción útil del calor y del trabajo

Reemplazando 1° principio en la fórmula de exergía:

Exergía desglosadaΔX = (Q − T0 · ΔS) − (W − p0 · ΔV)

(Q − T0·ΔS) = porción útil del calor. (W − p0·ΔV) = porción útil del trabajo.

Exergía de una fuente de T constante

Variación de exergía de una fuente a temperatura T que intercambia calor Q (positivo si recibe, negativo si cede):

Exergía por calorΔX = (1 − T0T) · Q

El factor cambia de signo según T esté arriba o debajo de T0. Si T = T0 → exergía cero.

Criterios de posibilidad de un proceso
  • 1° principio: QH = W + QL (conservación de la energía).
  • Carnot: η ≤ ηCarnot → el trabajo no puede superar el límite reversible.
  • Entropía: ΔSU ≥ 0 → la entropía del universo no puede disminuir.
  • Exergía: ΔXU ≤ 0 → la exergía del universo no puede aumentar.
  • ηX ≤ 1 → no se puede ganar más exergía de la que se pierde.

Cuando el simulador marca "imposible", alguno de estos criterios se viola.
